# Skripsi-SIMPRES-Segmentasi-Prestasi-Siswa-301220058
SIMPRES (Sistem Informasi Segmentasi Prestasi Siswa) merupakan aplikasi untuk mengelompokkan tingkat prestasi akademik siswa menggunakan algoritma K-Means dengan optimasi Elbow Method. Sistem ini membantu sekolah mengidentifikasi kategori prestasi siswa berdasarkan data nilai akademik secara otomatis, objektif, dan terukur.
